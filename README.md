## Projetos

### [Blender Dashboard](https://github.com/TheDuit/blenderDashboard)

Dashboard para visualização e comparação de dados de desempenho do Blender Open Data.

- Visualização de dados com Recharts
- Estilização com Styled Components
- Consumo e transformação de dados externos
- Interface voltada à comparação de dispositivos

### [Blender Open Data Caller](https://github.com/TheDuit/BlenderOpenDataCaller)

Serviço responsável pela consulta e disponibilização dos dados utilizados pelo Blender Dashboard.

- Integração com o Blender Open Data
- Processamento de requisições externas
- Separação entre Front-End e serviço de dados

### [ZapBot](https://github.com/TheDuit/zapBot)

Projeto de automação e integração com serviços de mensagens.

### [Floating Element](https://github.com/TheDuit/FloatingElement)

Experimento de interface e comportamento visual para elementos flutuantes.
